# AI Ügynök Ökoszisztéma Kutatási Eredmények (2026.07.06)

## Legfontosabb Protokollok és Architektúrák

### 1. LOKA Protocol (Layered Orchestration for Knowledgeful Agents)
- **Forrás**: arxiv.org/pdf/2504.10915
- **Jellemzők**: Universal Agent Identity Layer (UAIL), DID + VC, Decentralized Ethical Consensus Protocol (DECP)
- **Status**: Kutatási szakasz, koncepcionális keretrendszer

### 2. Anda.ai
- **Forrás**: anda.ai
- **Jellemzők**: Open standard agent memória (KIP), Agent Protocols, Rust alapú, ICP on-chain identity
- **Status**: DAO, aktív fejlesztés, open source

### 3. OAP Foundation (Open Agent Protocol)
- **Forrás**: oap.foundation/OAP-Whitepaper-V6.en.pdf
- **Jellemzők**: OAEP (Layer 0 - Trust), OACP (Layer 1 - Commerce), eIDAS compliant, Holochain
- **Cél**: "Airbus for the Personal AI" — európai digitális szuverenitás
- **Status**: Foundation alakulóban, Q4 2025-Q3 2026

### 4. Nanda Unified Architecture / Trust Fabric
- **Forrás**: arxiv.org/html/2507.07901v3
- **Jellemzők**: 5 réteg (Discovery, Composition, Execution, Evaluation, Incentivization), X42/H42 micropayments, MAESTRO security
- **Status**: Akadémiai + enterprise (Synergetics, Cisco Agency Framework)

### 5. Inai
- **Forrás**: github.com/ch4r10t33r/inai
- **Jellemzők**: P2P discovery (libp2p + Kademlia DHT), DID identity, x402 payments, MCP bridge
- **Status**: Aktív fejlesztés, multi-language (TypeScript, Python, Rust, Zig)

### 6. Lucid-L2
- **Forrás**: github.com/lucid-fdn/Lucid-L2
- **Jellemzők**: On-chain identity (Solana + EVM), agent memory, compute deployment, x402 payments, reputation
- **Status**: Production-ready egyes komponensek, private beta cloud

### 7. VAMS
- **Forrás**: github.com/GodOfAgents/VAMS
- **Jellemzők**: DePIN compute, multi-chain routing (Polygon, Cardano), DBOS state recovery, TEE
- **Status**: Fejlesztés alatt, PoC szakasz

## Következtetés
A piac éppen most alakul ki. A DömösAiTech célja egy európai szabványoknak megfelelő, decentralizált, multi-agent ökoszisztéma építése, amely integrálja:
- Szuverén identitást (DID/VC)
- Lokális és DePIN compute-ot
- Nyílt protokollokat (MCP, A2A, OAP)
- EU AI Act compliance-t
- Multi-szektor felhasználást (smart home, enterprise, government, content)
