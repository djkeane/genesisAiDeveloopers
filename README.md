## Core Philosophy

- **"Code moves, data stays"** — local-first, sovereign infrastructure
- **"Human-in-the-loop"** — oversight, not replacement
- **Privacy-by-design** — no leakage, no centralized exfiltration
- **Self-improvement** — Thompson Sampling, OpenClaw-RL, EvoClaw
